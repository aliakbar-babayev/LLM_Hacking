## 🧠 Core Concepts Quick Reference

- **Overfitting** — Model too specific to training data → poor generalization
- **Gradient** — Direction of steepest loss increase → backprop uses this
- **Attention** — Mechanism letting tokens focus on relevant other tokens
- **Latent Space** — Compressed learned representation of data
- **Decision Boundary** — The line/surface a classifier uses to separate classes
