# LLM Hacking

Personal notes and write-ups from my journey learning **LLM / AI security** through [Hack The Box Academy](https://academy.hackthebox.com/).

> ⚠️ **Disclaimer:** This repository is for educational purposes only. All techniques were practiced in authorized lab environments. Do not use them against systems you do not own or have explicit permission to test.

## 🎯 Topics Covered

- LLM fundamentals (tokens, context windows, system prompts)
- Prompt injection (direct and indirect)
- Jailbreaking techniques
- Data leakage and system prompt extraction
- Insecure output handling
- Excessive agency and tool abuse
- OWASP Top 10 for LLM Applications
- Mitigations and defensive considerations
